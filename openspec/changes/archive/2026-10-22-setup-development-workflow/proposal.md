# Proposal

## Why

The repository is about to be refactored with Claude as the implementer, and nothing currently constrains how that work is done: linters are installed but unconfigured, dependencies mix runtime, dev and notebook concerns, and there is no contract describing code style, documentation boundaries or how the OpenSpec loop handles deviations. Without that contract, quality degrades with every locally-reasonable edit; it has to exist before the refactor starts, not after.

## What Changes

- **BREAKING** Move the project to Python 3.14 (`.python-version`, `requires-python`).
- Configure ruff with every rule enabled (preview on, for the `DOC` rules) and ty with every rule raised to error; the only exceptions live in `pyproject.toml`, each with a reason recorded in `design.md`. Inline `# noqa` and `# type: ignore` are banned.
- Ban imports of oracle libraries (`roboticstoolbox`, `spatialmath`) from `src/`.
- Remove mypy, pylint and nbqa; reorganize dependencies into runtime, `dev` and `notebooks` groups, pinning ruff, ty and ast-grep exactly.
- Add hypothesis, pre-commit, roboticstoolbox-python (test oracle) and ast-grep-cli as dev dependencies.
- Add a Claude Code `PostToolUse` hook that formats, lints and type-checks the edited Python file, silent on success.
- Add a pre-commit configuration running the same checks through the locked environment.
- Add `CLAUDE.md` as the working contract: roles, disagreement, code style, documentation split, navigation and token discipline, workflow loop.
- Fill `openspec/config.yaml` with project context, artifact rules and apply/archive guidance implementing the deviation loop.
- Activate Serena for symbol-level navigation.
- Write the README: what the repository is and how to set it up.

## Capabilities

### New Capabilities

None. This change configures tooling and the working process; it adds no behavior to the `robotic` package. The change sets `skip_specs: true`; the conventions it establishes live in `CLAUDE.md`, `pyproject.toml` and `openspec/config.yaml`, and their rationale in `design.md`.

### Modified Capabilities

None.

## Impact

- `pyproject.toml`, `uv.lock`, `.python-version`: Python version, dependency groups, ruff and ty configuration.
- New files: `CLAUDE.md`, `.claude/hooks/` (hook script), `.claude/settings.json` (plugins and hook registration), `.pre-commit-config.yaml`, `.serena/project.yml`.
- Generated by `openspec init`: `.claude/commands/opsx/`, `.claude/skills/openspec-*/`, `openspec/specs/`, `openspec/changes/archive/`.
- Modified: `openspec/config.yaml`, `README.md`. `.gitignore` is unchanged: Serena ships its own `.serena/.gitignore` for its cache.
- `src/` and `tests/` are not modified. Legacy files will fail the new checks; they are brought into compliance by the upcoming refactor, file by file, as the hook only checks files being edited.
- Runtime dependencies currently imported by legacy code (loguru, matplotlib, pandas) stay until the refactor removes their use.

## Out of Scope (recorded for later changes)

- Kinematics refactor and the symbolic/numeric API design.
- Project-wide check gate (`Stop` hook running all checks): enabled after the refactor, when the whole tree is expected to pass.
- Documentation site generator for `docs/`: chosen when there is content to publish (see `design.md`).
- Simulation with Newton (+ Warp): sensors (camera, IMU, contact, frame transform) and URDF/MJCF/USD importers cover the expected needs; USD keeps Isaac Sim reachable later. Visualization (Newton viewer vs rerun) is decided together with it.
- Custom ast-grep lint rules: added when a rule ruff cannot express is needed.
- CI workflow (`.github/_workflows/tests.yml` is currently disabled; it still pins Python 3.13.2 and must move to 3.14 when re-enabled).
